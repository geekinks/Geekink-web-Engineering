# Student Guide

Arrive prepared to build every weekday. Read the session before class, work through the guided example, then attempt the independent exercise before asking for a solution. Commit small changes, write down test evidence, and keep your README current.

Use GitHub throughout. When requesting help, share the smallest reproducible example, what you expected, what happened, and what you already tried. A screenshot, command output or local evidence is acceptable when bandwidth makes video impractical.

Treat connectivity as uncertain: save drafts locally, test loading and error states, avoid needless downloads, and never claim a submission synchronized until it has. Submit each week's repository and reflection using the [submission guidelines](docs/submission-guidelines.md).
