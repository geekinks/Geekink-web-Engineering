# Assessment Guide

Weekly assessment is practical: students must independently apply the week's ideas in a documented project.

| Assessment | Weight |
| --- | ---: |
| Understanding of concepts | 15% |
| Practical coding exercises | 20% |
| Weekly assignment | 20% |
| GitHub contribution and documentation | 10% |
| Weekly mini-project | 20% |
| Participation and code review | 5% |
| Final capstone | 10% |

Use [the weekly template](assessments/weekly-assessments/template.md), [coding challenge template](assessments/practical-challenges/template.md), and [capstone rubric](assessments/capstone-rubric.md). A polished interface does not pass if it excludes keyboard users, exposes data, or loses important work during a foreseeable failure.
