# Code Review Checklist

- [ ] The feature matches the stated user need and acceptance criteria.
- [ ] Names, components or functions are understandable and focused.
- [ ] Normal, empty, invalid and failure paths are considered.
- [ ] Keyboard use, labels, contrast and semantics were checked.
- [ ] Data access is authorized; no secrets are exposed.
- [ ] Assets, requests and dependencies are proportionate to a modest device/network.
- [ ] README, tests and setup instructions are sufficient to reproduce the work.

Leave one specific observation, one question and one actionable suggestion.
