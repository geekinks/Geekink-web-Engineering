# Practical Coding Challenge

## Scenario

Describe a small real-world user problem, including a device or network constraint.

## Requirements

- Build the core behaviour without unnecessary libraries.
- Validate input and show an accessible failure state.
- Add one automated or reproducible manual test.
- Commit work and document setup and trade-offs.

## Evaluation

Assess correctness, clarity, resilience, accessibility, documentation and explanation—not visual polish alone.
