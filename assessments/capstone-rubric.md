# Capstone Evaluation Rubric

| Area | Weight | Evidence |
| --- | ---: | --- |
| Problem definition, PRD, SRS, personas and journey | 15% | Traceable requirements and scope |
| Architecture, data design and implementation | 25% | Working accessible core flow |
| Security, authorization and validation | 15% | Threat/role decisions and tests |
| Offline-first resilience and low-resource design | 15% | Local persistence, recovery, sync/conflict policy |
| Testing, performance, accessibility and SEO | 15% | Audit and test evidence |
| Deployment, documentation, demo and reflection | 15% | Reproducible deployment and honest presentation |

The project must use Next.js and Supabase or Firebase as its primary backend. It must not expose secrets or claim offline synchronization that it cannot prove.
