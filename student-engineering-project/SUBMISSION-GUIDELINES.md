# Submission Guidelines

Submit the repository, deployed URL where applicable, setup steps, environment-variable names only, screenshots, demo or written walkthrough, tests, architecture, limitations, and retrospective.

## Traceability matrix

| Product requirement | Learning concept | Curriculum days | Milestone | Assessment evidence |
| --- | --- | --- | --- | --- |
| User signs in and sees only their records | Auth, authorization, RLS/Rules | 081–090, 092 | Data integration | Policy/rule tests and demo |
| User work survives interruption | IndexedDB, service workers, idempotency | 049–050, 096 | Quality hardening | Offline/retry test |
| Core flow works for keyboard users | Semantic HTML, React testing, audit | 018–020, 070, 097 | Static core + quality | Audit findings and fixes |
