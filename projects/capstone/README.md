# Production Capstone

Build and deploy a web application that solves a real problem in education, business, agriculture, healthcare, community development or another relevant sector. The suggested project is a **GeekInk Learning Platform** with registration/authentication, course catalogue, materials, dashboard, progress tracking, assignment submission, an admin view and selected offline content.

Use Next.js with **either Supabase or Firebase** as the primary backend. The required artefacts are a problem statement, proposal, PRD, SRS, personas, user journey, wireframes, architecture, database design, implementation, tests, deployment and technical documentation. Complete the [student engineering project package](../../student-engineering-project/) and assess with the [capstone rubric](../../assessments/capstone-rubric.md).

Offline capability must identify safe cached content, local data persistence, network state, queued submissions, retry behaviour, synchronization triggers and conflict handling. Never cache private data without a logout and retention policy.
