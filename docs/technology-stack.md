# Technology Stack

- **Web platform:** HTML5, CSS3, responsive design, JavaScript ES6+, DOM, Browser APIs, Fetch and TypeScript.
- **Frontend:** React, Hooks, Context API, forms, routing, API integration, accessibility and performance.
- **Full stack:** Next.js App Router, Server and Client Components, Server Actions, Route Handlers, metadata, middleware and deployment.
- **Data and BaaS:** PostgreSQL, Supabase and Firebase.

Supabase is Postgres-centred and uses SQL, migrations and Row Level Security. Firebase is document/realtime-service-centred, with Security Rules and offline SDK support. Neither removes the need for data modelling, authorization, validation or cost awareness. Week 11 asks learners to choose based on access patterns, offline needs, realtime behaviour, team skills, security model and lock-in.
