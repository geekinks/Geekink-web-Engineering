# Glossary

- **API:** An interface through which software exchanges data or actions.
- **Authentication:** Establishing who a user is.
- **Authorization:** Deciding what an authenticated user may do.
- **BaaS:** Backend-as-a-Service; managed backend capabilities used through APIs and SDKs.
- **Cache:** Stored data used to reduce repeated network work; it needs an expiration and privacy policy.
- **Client:** Software, often a browser, that requests a service.
- **CRUD:** Create, read, update and delete operations.
- **DNS:** System that resolves a domain name to network records.
- **IndexedDB:** Browser database for structured local data.
- **PWA:** Web application enhanced with installability and resilient offline behaviour.
- **RLS:** Row Level Security, database policies that restrict rows a user can access.
- **Service worker:** Browser worker that can intercept requests and manage caches; it does not automatically solve synchronization.
