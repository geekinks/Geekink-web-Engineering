# Programme Overview

GeekInk Web Engineering runs for three months: 12 weeks, five structured sessions each week, 60 sessions total. Monday introduces foundations, Tuesday deepens with an example, Wednesday practises implementation, Thursday builds a real feature, and Friday assesses, reviews and reflects. Saturday is optional support; Sunday is rest.

The programme moves from the web platform through frontend engineering and full-stack delivery. It teaches both Supabase and Firebase only after learners understand HTTP, trust boundaries, data modelling and relational databases. It is designed for practical learning in low-resource settings.
