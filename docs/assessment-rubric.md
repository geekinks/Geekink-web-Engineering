# Assessment Rubric

| Dimension | Weight | Evidence |
| --- | ---: | --- |
| Conceptual understanding | 20% | Explanation and decisions |
| Functionality | 25% | Acceptance criteria and test evidence |
| Engineering quality | 20% | Structure, types, validation, Git |
| Accessibility, security, resilience | 20% | Audits and failure paths |
| Documentation and reflection | 15% | README, submission, learning notes |

Assess as emerging, developing, proficient, or exemplary. A visually attractive product cannot pass if it exposes secrets, excludes keyboard users, or loses important work on failure.
