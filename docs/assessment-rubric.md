# Assessment Rubric

This supporting rubric follows the programme-wide [assessment guide](../ASSESSMENT-GUIDE.md).

| Dimension | Weight | Evidence |
| --- | ---: | --- |
| Understanding of concepts | 15% | Explanation and decisions |
| Practical coding exercises | 20% | Working attempts and test evidence |
| Weekly assignment | 20% | Acceptance criteria and reflection |
| GitHub contribution and documentation | 10% | Commits, README and setup notes |
| Weekly mini-project | 20% | Independent, accessible implementation |
| Participation and code review | 5% | Helpful review and response to feedback |
| Final capstone | 10% | Rubric evidence and presentation |

Use the [weekly assessment template](../assessments/weekly-assessments/template.md). A visually attractive product cannot pass if it exposes secrets, excludes keyboard users, or loses important work on foreseeable failure.
