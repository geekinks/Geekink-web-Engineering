# Submission Guidelines

For each weekly project submit a GitHub repository or pull request containing a readable README, setup steps, feature list, test/failure-path evidence, accessibility checks and a reflection. Link deployed work when available, but local evidence is accepted when connectivity is limited.

Never submit secrets, learner data or service-role credentials. Include an `.env.example` with names only. Friday submissions include one thoughtful peer review using the [code review template](../templates/code-review-template.md).
