# 12-Week Roadmap

The learning order protects prerequisites: learners master browser and JavaScript foundations before React, React before Next.js, and backend/database concepts before either BaaS platform.

| Weeks | Engineering focus | Project progression |
| --- | --- | --- |
| 1–3 | Web, semantic HTML, responsive CSS | Introduction page → form → portfolio |
| 4–6 | JavaScript, browser APIs, TypeScript | Calculator → offline-aware task app → typed app |
| 7–9 | React, frontend architecture, Next.js | Dashboard → portal → full-stack portal |
| 10–11 | PostgreSQL/Supabase and Firebase | Student platform → collaboration app |
| 12 | Production engineering and capstone | Deployed real-world solution |

Offline-first practices recur from local setup and efficient assets through storage, IndexedDB, service workers, BaaS offline behaviour, queues, synchronization and conflict handling. Open [Week 1](weeks/week-01-web-engineering-foundations/) to start.
