# Module 05: Advanced JavaScript and Browser Engineering

## Outcome

Browser engineering. Complete each daily lesson, then submit the module checkpoint with a README, evidence of testing, and reflection.

| Day | Lesson | Focus |
| ---: | --- | --- |
| 041 | [Modern JavaScript syntax](day-041/) | template literals, optional chaining, nullish coalescing, and concise syntax |
| 042 | [Destructuring, spread, and rest](day-042/) | immutable updates, destructuring, rest parameters, and shallow copies |
| 043 | [Array methods and data pipelines](day-043/) | map, filter, reduce, find, sort, and non-mutating patterns |
| 044 | [Objects, prototypes, and defensive data](day-044/) | object utilities, prototypes, ownership, and safe property access |
| 045 | [Modules and application boundaries](day-045/) | import, export, dependency direction, and browser modules |
| 046 | [Errors and failure-aware interfaces](day-046/) | throw, try/catch/finally, Error objects, and user-safe error states |
| 047 | [Promises and the event loop](day-047/) | pending, fulfilled, rejected, microtasks, chaining, and concurrency |
| 048 | [Async/await and Fetch](day-048/) | async functions, HTTP failure checks, cancellation, Fetch API, and JSON |
| 049 | [Browser storage](day-049/) | localStorage, sessionStorage, serialization, quotas, and privacy |
| 050 | [IndexedDB, service workers, and offline UX](day-050/) | structured local data, caching, manifests, queues, retries, and browser limits |

## Module checkpoint

Integrate the final three days into a small, accessible Community Learning Hub milestone. Explain the user problem, decisions, test evidence, and an offline or low-resource consideration.
