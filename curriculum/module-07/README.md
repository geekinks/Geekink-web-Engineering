# Module 07: React.js Engineering

## Outcome

React. Complete each daily lesson, then submit the module checkpoint with a README, evidence of testing, and reflection.

| Day | Lesson | Focus |
| ---: | --- | --- |
| 061 | [React's model and JSX](day-061/) | declarative UI, JSX, rendering, and Vite development |
| 062 | [Components, props, and composition](day-062/) | single responsibility, props, children, and component boundaries |
| 063 | [State and event handling](day-063/) | useState, event handlers, immutable updates, and derived state |
| 064 | [Conditional UI and lists](day-064/) | conditional rendering, keys, empty states, and list updates |
| 065 | [Controlled forms](day-065/) | controlled inputs, validation, submission, and focus management |
| 066 | [Effects and data synchronization](day-066/) | useEffect, dependencies, cleanup, fetching, and race conditions |
| 067 | [Refs, memoization, and performance](day-067/) | useRef, useMemo, useCallback, profiling, and when not to optimize |
| 068 | [Context and state boundaries](day-068/) | Context API, provider design, local versus shared state, and testability |
| 069 | [Custom hooks and routing](day-069/) | custom hook contracts, React Router, nested routes, and URL state |
| 070 | [React architecture and testing](day-070/) | feature boundaries, error boundaries, React Testing Library, and user-focused tests |

## Module checkpoint

Integrate the final three days into a small, accessible Community Learning Hub milestone. Explain the user problem, decisions, test evidence, and an offline or low-resource consideration.
