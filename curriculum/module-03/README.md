# Module 03: CSS3 and Responsive Web Design

## Outcome

CSS and responsive layout. Complete each daily lesson, then submit the module checkpoint with a README, evidence of testing, and reflection.

| Day | Lesson | Focus |
| ---: | --- | --- |
| 021 | [CSS rules, cascade, and inheritance](day-021/) | selectors, declarations, cascade order, and inherited properties |
| 022 | [Selectors and specificity](day-022/) | selector matching, specificity, and maintainable naming |
| 023 | [The box model](day-023/) | content, padding, border, margin, sizing, and overflow |
| 024 | [Colour, typography, and design tokens](day-024/) | readability, font stacks, relative units, and custom properties |
| 025 | [Display, flow, and positioning](day-025/) | block, inline, normal flow, relative, absolute, sticky, and fixed |
| 026 | [Flexible one-dimensional layouts](day-026/) | Flexbox axes, wrapping, alignment, and gap |
| 027 | [Two-dimensional layouts with Grid](day-027/) | tracks, minmax, auto-fit, areas, and intrinsic sizing |
| 028 | [Mobile-first responsive design](day-028/) | fluid sizing, breakpoints, touch targets, and content priority |
| 029 | [Media queries and responsive media](day-029/) | media features, prefers-reduced-motion, container-aware thinking, and images |
| 030 | [Transitions, animation, and CSS checkpoint](day-030/) | transitions, keyframes, performance-friendly properties, and restraint |

## Module checkpoint

Integrate the final three days into a small, accessible Community Learning Hub milestone. Explain the user problem, decisions, test evidence, and an offline or low-resource consideration.
