# Module 04: JavaScript Programming

## Outcome

JavaScript foundations. Complete each daily lesson, then submit the module checkpoint with a README, evidence of testing, and reflection.

| Day | Lesson | Focus |
| ---: | --- | --- |
| 031 | [JavaScript execution and values](day-031/) | scripts, strict mode, variables, primitives, and expressions |
| 032 | [Variables, types, and conversions](day-032/) | let, const, strings, numbers, booleans, null, undefined, and coercion |
| 033 | [Operators, comparisons, and decisions](day-033/) | operators, equality, truthiness, conditionals, and guard clauses |
| 034 | [Loops and repetition](day-034/) | for, while, for...of, iteration, and avoiding infinite loops |
| 035 | [Functions and parameters](day-035/) | declarations, expressions, parameters, return values, and pure functions |
| 036 | [Arrays and collection thinking](day-036/) | indexes, mutation, iteration, and collection operations |
| 037 | [Objects and modeling data](day-037/) | properties, methods, references, and nested data |
| 038 | [Scope, closures, and debugging](day-038/) | lexical scope, closures, call stacks, and breakpoints |
| 039 | [The DOM as a programming interface](day-039/) | querying, creating, updating, and removing elements |
| 040 | [Events and interactive forms](day-040/) | event listeners, delegation, default behaviour, and form events |

## Module checkpoint

Integrate the final three days into a small, accessible Community Learning Hub milestone. Explain the user problem, decisions, test evidence, and an offline or low-resource consideration.
