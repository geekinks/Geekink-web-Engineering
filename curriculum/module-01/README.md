# Module 01: Introduction to Web Engineering

## Outcome

Web foundations. Complete each daily lesson, then submit the module checkpoint with a README, evidence of testing, and reflection.

| Day | Lesson | Focus |
| ---: | --- | --- |
| 001 | [The web, the internet, and a useful mental model](day-001/) | internet protocols, the World Wide Web, and URLs |
| 002 | [Clients, servers, and requests](day-002/) | client-server architecture and request/response boundaries |
| 003 | [Browsers and the rendering pipeline](day-003/) | parsing HTML and CSS, JavaScript execution, and DevTools |
| 004 | [Domains, DNS, and hosting](day-004/) | domain names, DNS resolution, IP addresses, and hosting |
| 005 | [HTTP, HTTPS, and status codes](day-005/) | methods, headers, status codes, TLS, and secure transport |
| 006 | [Development environment and terminal](day-006/) | VS Code, Node.js, a browser, and command-line navigation |
| 007 | [Git: local history and recovery](day-007/) | repositories, commits, branches, and meaningful checkpoints |
| 008 | [GitHub collaboration](day-008/) | remotes, pull requests, issues, and code review |
| 009 | [Developer tools and debugging](day-009/) | Elements, Console, Sources, Network, and accessibility inspectors |
| 010 | [Foundation checkpoint: publish a web profile](day-010/) | planning, repository hygiene, and static deployment |

## Module checkpoint

Integrate the final three days into a small, accessible Community Learning Hub milestone. Explain the user problem, decisions, test evidence, and an offline or low-resource consideration.
