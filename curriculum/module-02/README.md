# Module 02: HTML5 and Semantic Web Development

## Outcome

HTML and accessible content. Complete each daily lesson, then submit the module checkpoint with a README, evidence of testing, and reflection.

| Day | Lesson | Focus |
| ---: | --- | --- |
| 011 | [HTML documents and the document tree](day-011/) | doctype, html, head, body, metadata, and nesting |
| 012 | [Text content with meaning](day-012/) | headings, paragraphs, emphasis, quotations, and document outline |
| 013 | [Links and navigation](day-013/) | relative URLs, absolute URLs, landmarks, and skip links |
| 014 | [Lists, tables, and structured data](day-014/) | when lists and data tables communicate meaning |
| 015 | [Images, audio, and video](day-015/) | alt text, captions, responsive media, and attribution |
| 016 | [Forms and user input](day-016/) | labels, input types, fieldsets, names, and form submission |
| 017 | [Native validation and helpful errors](day-017/) | constraints, required fields, patterns, and error messaging |
| 018 | [Semantic page regions](day-018/) | header, nav, main, article, section, aside, and footer |
| 019 | [Accessibility foundations](day-019/) | keyboard access, names, roles, values, contrast, and progressive enhancement |
| 020 | [SEO and HTML platform APIs](day-020/) | metadata, structured discoverability, dialogs, details, and progressive features |

## Module checkpoint

Integrate the final three days into a small, accessible Community Learning Hub milestone. Explain the user problem, decisions, test evidence, and an offline or low-resource consideration.
