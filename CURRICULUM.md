# Curriculum

The GeekInk programme is a 12-week, Monday–Friday curriculum. Each week contains five learning sessions with objectives, concepts, lesson content, guided examples, coding activities, exercises, expected output, homework and official resources.

| Week | Learning focus | Core project |
| --- | --- | --- |
| [Week 1](weeks/week-01-web-engineering-foundations/) | Internet, web, HTTP(S), DNS, browsers, Git/GitHub | Personal introduction webpage |
| [Week 2](weeks/week-02-html-fundamentals/) | HTML5, semantics, forms, accessibility | Profile and registration form |
| [Week 3](weeks/week-03-css-responsive-design/) | CSS3, Flexbox, Grid, responsive design | Portfolio |
| [Week 4](weeks/week-04-javascript-fundamentals/) | JavaScript programming and DOM | Result calculator |
| [Week 5](weeks/week-05-javascript-browser-engineering/) | Browser APIs, storage, Fetch, async, offline UX | Task manager |
| [Week 6](weeks/week-06-typescript/) | TypeScript and maintainable code | Typed task manager |
| [Week 7](weeks/week-07-react-fundamentals/) | React components, props, state, hooks, forms | Student dashboard |
| [Week 8](weeks/week-08-advanced-react/) | Context, routing, API integration, architecture | Student portal frontend |
| [Week 9](weeks/week-09-nextjs-fullstack/) | App Router, server/client components, actions, routes | Next.js portal |
| [Week 10](weeks/week-10-supabase/) | PostgreSQL, Supabase, Auth, RLS, Storage, Realtime | Student manager |
| [Week 11](weeks/week-11-firebase/) | Firebase Auth, Firestore, RTDB, Functions, Rules, Hosting | Collaboration app |
| [Week 12](weeks/week-12-production-capstone/) | Security, testing, PWA, deployment, documentation | Production capstone |

Saturday is optional revision, project completion or mentorship. Sunday is for rest and preparation. Assessment and deliverables are defined in the [assessment guide](ASSESSMENT-GUIDE.md).
