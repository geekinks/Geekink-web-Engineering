# GeekInk Web Engineering

**Twelve weeks. Sixty practical learning sessions. Production-minded web engineers.**

GeekInk Innovations Ltd provides a beginner-friendly, project-driven web engineering programme for aspiring technology professionals and technopreneurs, especially learners working with constrained connectivity, electricity and devices.

## Programme at a glance

- **Duration:** 3 months / 12 weeks / 60 structured sessions.
- **Schedule:** Monday–Friday learning; Saturday optional revision, project completion or mentorship; Sunday rest and preparation.
- **Path:** web foundations → HTML → CSS → JavaScript → browser engineering → TypeScript → React → Next.js → Supabase → Firebase → production capstone.
- **Method:** understand the concept, build a small slice, test it, commit it, document it, review it.

## Engineering standards

Fundamentals come before frameworks. Every project considers accessibility, security, performance, maintainability and unreliable connectivity. Offline support means honest local persistence, network state, retry and conflict behaviour—not simply adding a service worker.
