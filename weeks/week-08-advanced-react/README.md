# Week 8: Advanced React and Frontend Engineering

**Outcome:** By Friday, students can deliver **Multi-page student portal frontend** and explain the engineering decisions behind it.

Monday to Friday are structured learning sessions. Saturday is optional revision, project completion or mentorship; Sunday is rest and preparation.

| Session | Topic | Key concepts |
| --- | --- | --- |
| Monday | [Effects, API integration and resilient states](monday.md) | useEffect cleanup; loading/error/empty; fetch cancellation; data boundaries |
| Tuesday | [Routing and page architecture](tuesday.md) | React Router; nested routes; URL state; layouts; route guards as UX |
| Wednesday | [Context, custom hooks and forms](wednesday.md) | Context API; provider scope; custom hooks; validation; reusable controls |
| Thursday | [Performance, accessibility and offline enhancement](thursday.md) | memoization measurement; code splitting; focus; PWA concepts; IndexedDB |
| Friday | [Portal architecture review](friday.md) | state management fundamentals; code review; API contracts; quality checklist |

## Weekly deliverables

- A GitHub repository with small commits and a clear README.
- The week's practical project, including normal and failure-path evidence.
- A Friday reflection and one peer-review contribution.

## Offline-first thread

Each week considers a realistic constraint: limited data, interrupted electricity, modest hardware, unreliable requests, locally saved work, or safe synchronization. See [resources.md](resources.md) and the programme [offline-first guide](../../docs/offline-first-web-engineering.md).

## Assessment

Use the [weekly assessment template](../../assessments/weekly-assessments/template.md). The mini-project is assessed against functionality, clarity, accessibility, resilience and documentation.
